## ⚠️ 已知问题

### Electron ES Module 导入问题

**问题描述**:
```
SyntaxError: The requested module 'electron' does not provide an export named 'app'
```

**原因**:
- 项目设置为 `"type": "module"` (ES Module 模式)
- Electron 模块不完全支持 ES Module 的静态导入
- database/index.js 中使用了 `import { app } from 'electron'`

**解决方案**:

有以下几种选择:

1. **使用动态导入** (推荐)
   ```typescript
   // 将静态导入改为动态导入
   const electron = await import('electron');
   const { app } = electron;
   ```

2. **将 database 模块改为 CommonJS**
   ```typescript
   // database/index.ts 改为 .cts 扩展名或使用 require()
   ```

3. **使用 Electron 的 ES Module 支持**
   - 需要 Electron 28+ 的实验性 ES Module 支持
   - 需要调整 package.json 配置

4. **修改 package.json,移除全局 `"type": "module"`**
   - 为不同目录设置不同的模块类型
   - 可能影响其他部分

### MessagePort 类型问题

**问题描述**:
```
'MessagePort' refers to a value, but is being used as a type here
```

**已解决**: 使用 `any` 类型替代 MessagePort 类型注解

## 📋 使用指南

### 前端使用示例

```typescript
// 1. 提交任务
const { taskId } = await window.electronAPI.agent.submitTask({
  type: 'chat',
  payload: {
    messages: [
      { role: 'user', content: '你好' }
    ]
  }
});

// 2. 监听任务更新
const cleanup = window.electronAPI.agent.onTaskUpdate((update) => {
  console.log('任务状态:', update.status);
  console.log('任务结果:', update.result);
});

// 3. 取消任务
await window.electronAPI.agent.cancelTask(taskId);

// 4. 清理监听器
cleanup();
```

### 可用的任务类型

1. **CHAT** - AI 对话
   ```typescript
   {
     type: 'chat',
     payload: {
       messages: [{ role: 'user', content: '消息内容' }]
     }
   }
   ```

2. **SUMMARIZE** - 文本摘要
   ```typescript
   {
     type: 'summarize',
     payload: {
       text: '需要摘要的文本'
     }
   }
   ```

3. **ANALYZE_BOOK** - 书籍分析
   ```typescript
   {
     type: 'analyze_book',
     payload: {
       bookId: 'book-id'
     }
   }
   ```

4. **READING_ASSIST** - 阅读辅助
   ```typescript
   {
     type: 'reading_assist',
     payload: {
       text: '需要处理的文本',
       action: 'explain' | 'translate' | 'expand'
     }
   }
   ```
