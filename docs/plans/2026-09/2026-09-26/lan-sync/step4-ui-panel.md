## 目标
数据中心「设备同步」面板可用：对端状态、一键同步、结果/冲突展示、可选项开关；启动时对端变化通知。

## 计划改动
- [ ] 新建 store `stores/sync-store.ts`（命名遵守 xxx-store.ts 规范）：peers、syncState、进行中报告、历史；事件订阅 tipc `syncEvent`
- [ ] 数据中心新增「设备同步」面板（路由/导航挂入数据中心现有面板体系，参考用量/记忆面板的挂载方式）：
  - 对端卡片：设备名、在线状态、上次同步时间、「同步」按钮（进行中显示进度：已传输文件数/字节）
  - 结果区：拉取/推送/冲突/跳过计数；冲突文件列表（点击定位文件）；跳过文件列表与原因
  - 设置区：设备名编辑、可选项开关（行情数据、飞书数据）
  - 配对流程 UI：发起配对 → 显示/输入 6 位码 → 成功态
- [ ] 启动通知：应用启动发现已配对对端在线且对端有新变化（清单摘要比对）时，用现有通知中心发一条「检测到 XX 端有更新，点击同步」——点击跳转面板。注意：启动即拉清单有流量成本，仅对已配对且在线对端做一次摘要查询（握手包带 manifest hash 短摘要）
- [ ] 验证：Windows 双实例走完整 UI 流程（配对→改数据→通知→一键同步→结果展示→冲突副本可见）
- [ ] `bun run build:electron` + lint 通过
