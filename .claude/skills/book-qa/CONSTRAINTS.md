# Book QA 约束规则示例

## 正确 vs 错误示例

### 示例 1: 书中存在的内容

**问题：** "主角的性格是怎样的？"

| 类型 | 回答 |
|------|------|
| ❌ 错误 | 主角很勇敢，也很善良。他遇到困难从不放弃。 |
| ✅ 正确 | 根据原文，主角表现出勇敢和善良的特点 [第三章：危机]。面对危险时他选择挺身而出，也帮助过陌生人 [第五章：相遇]。 |

### 示例 2: 书中不存在的内容

**问题：** "书中有讲到量子力学吗？"

| 类型 | 回答 |
|------|------|
| ❌ 错误 | 量子力学是物理学的一个分支...（直接用训练数据回答） |
| ❌ 错误 | 书中可能提到了一些物理概念...（模糊回答） |
| ✅ 正确 | 很抱歉，搜索了所有章节后，没有找到与"量子力学"相关的内容。已搜索关键词：量子、力学、物理。 |

### 示例 3: 需要综合信息

**问题：** "故事的发展线索是什么？"

| 类型 | 回答 |
|------|------|
| ❌ 错误 | 故事大概是说主角从普通人变成英雄的过程... |
| ✅ 正确 | 根据章节结构：开端 [第一章] 主角是普通人；激励事件 [第二章] 遇到契机；发展 [第三-六章] 经历挑战；高潮 [第七章] 最终考验；结局 [第八章] 完成蜕变。 |

## 质量检查清单

回答前确认：

- [ ] 我调用 SearchBookContent 了吗？
- [ ] 我的答案基于搜索结果吗？
- [ ] 我标注了引用来源吗？
- [ ] 我避免了"可能"、"应该"等模糊词吗？
- [ ] 如果书中没有，我明确说明了吗？
- [ ] 我没有用外部知识"补充"答案吗？

## 禁止使用的表达模式

| 禁止 | 替代为 |
|------|--------|
| "可能..." | "书中提到..." 或 "书中没有提到..." |
| "应该..." | 明确说明或承认未知 |
| "大概..." | 给出确切答案或说明不确定 |
| "书中可能提到..." | "书中提到..." 或 "没有找到" |
| "根据我的知识..." | 只基于原文回答 |
