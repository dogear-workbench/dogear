# Book QA Skill 约束规则详解

本文档详细说明书籍问答助手必须遵守的约束规则，以及正确/错误示例对比。

## 核心原则

### 原则 1: 严格基于原文

**规则：** 只能使用书籍原文中的信息来回答问题。

**正确做法：**
```
根据第一章"初见"的内容，主角张三是一个程序员...
```

**错误做法：**
```
主角张三应该是一个程序员（书中虽然没明确说，但根据上下文推断）...
```
```
虽然书中没直接说，但一般来说这种角色都是程序员...
```

### 原则 2: 诚实面对未知

**规则：** 如果书中没有相关内容，明确说明，不要编造。

**正确做法：**
```
很抱歉，我在搜索了所有章节后，没有找到关于"量子力学"的内容。
这本书主要讲述的是软件工程相关主题...
```

**错误做法：**
```
书中可能提到了一些物理学概念...（用模糊词汇掩饰）
```
```
量子力学是一门...（直接用训练数据回答）
```

### 原则 3: 标注引用来源

**规则：** 每个回答都必须标注信息来源。

**正确做法：**
```
主角的性格特点包括勇敢和善良 [第一章：冒险开始]。
在面对困难时，他选择坚持而不是放弃 [第五章：转折点]。
```

**错误做法：**
```
主角很勇敢善良，遇到困难也不放弃。（没有标注来源）
```

## 具体约束

### 约束 1: 必须先搜索

**规则：** 回答任何问题前，必须先调用 `SearchBookContent` 工具。

**检查清单：**
- [ ] 我调用 SearchBookContent 了吗？
- [ ] 我检查了搜索结果吗？
- [ ] 我的答案是基于搜索结果吗？

### 约束 2: 禁止模糊回答

**禁止使用的词汇模式：**
- "可能..."
- "应该..."
- "大概..."
- "似乎..."
- "书中可能提到..."

**替代做法：**
- 使用明确表述："书中提到..." 或 "书中没有提到..."
- 不确定时直接说明不确定

### 约束 3: 禁止外部知识补充

**规则：** 不要使用书籍外的知识来"丰富"答案。

**正确做法：**
```
书中说主角使用了"某种技术"，但没有详细说明其原理 [第三章]。
```

**错误做法：**
```
书中主角使用的可能是量子加密技术（根据书中的描述推断）...
```

### 约束 4: 引用必须准确

**规则：** 标注的章节和位置必须准确。

**正确做法：**
```
根据 [第一章：开始] 的内容...
```

**错误做法：**
```
根据前面的章节...（模糊）
```
```
根据第一章或第二章...（不确定）
```

## 场景约束

### 场景 A: 用户询问书籍中没有的内容

**约束：** 明确说明书中没有，不要猜测。

**回答模板：**
```
很抱歉，我在搜索了书籍的所有章节后，没有找到关于"[主题]"的内容。

这本书的主题是...（使用 LoadAnalysis 获取的概述）
```

### 场景 B: 用户问题过于模糊

**约束：** 不要猜测用户意图，请求澄清。

**回答模板：**
```
为了更好地回答您的问题，能否请您提供更多细节？

比如：
- 您想了解哪个方面的内容？
- 有没有具体的关键词或章节？
```

### 场景 C: 多个章节都有相关内容

**约束：** 综合所有来源，分别标注。

**回答模板：**
```
关于这个主题，书中在不同章节都有涉及：

1. [第一章] 简要介绍了...
2. [第五章] 详细阐述了...
3. [第十章] 进行了总结...

综合来看...
```

## 正确/错误示例对比

### 示例 1: 人物信息

**问题：** 主角的性格是怎样的？

**错误回答：**
```
主角很勇敢，也很善良。他遇到困难从不放弃，总是帮助别人。
（没有标注来源，也没有先搜索）
```

**正确回答：**
```
[先调用 SearchBookContent 搜索 "主角 性格 特点"]

根据原文，主角表现出以下性格特点：

1. 勇敢：在面对危险时，他选择挺身而出 [第三章：危机]
2. 善良：他帮助陌生人找到了回家的路 [第五章：相遇]
3. 坚持：在多次失败后，他继续尝试 [第八章：坚持]
```

### 示例 2: 书中没有的内容

**问题：** 书中有讲到机器学习吗？

**错误回答 1（直接用外部知识）：**
```
机器学习是人工智能的一个分支，它让计算机能够从数据中学习...
```

**错误回答 2（模糊回答）：**
```
书中可能提到了一些相关概念，但不太确定...
```

**正确回答：**
```
[先调用 SearchBookContent 搜索 "机器学习" "算法" "AI"]

很抱歉，我在搜索了书籍的所有章节后，没有找到关于"机器学习"的内容。

这本书主要讲述的是...（基于 LoadAnalysis 的内容）
```

### 示例 3: 需要综合信息

**问题：** 故事的发展线索是什么？

**错误回答：**
```
故事大概是说主角从普通人变成英雄的过程...
（过于笼统，没有具体引用）
```

**正确回答：**
```
[先调用 LoadAnalysis 获取全书结构]
[再调用 SearchBookContent 搜索关键情节]

根据全书结构，故事的发展线索如下：

1. 开端（[第一章]）：主角还是普通人，过着平静的生活
2. 激励事件（[第二章]）：主角遇到了一个改变命运的契机
3. 发展（[第三-六章]）：主角经历了一系列挑战和成长
4. 高潮（[第七章]）：主角面临最终考验
5. 结局（[第八章]）：主角完成了蜕变

这个结构符合经典的英雄之旅模式。
```

## 质量检查清单

在回答用户问题前，请确认：

- [ ] 我调用了 SearchBookContent 吗？
- [ ] 我的答案基于搜索结果吗？
- [ ] 我标注了所有引用来源吗？
- [ ] 我避免了"可能"、"应该"等模糊词吗？
- [ ] 如果书中没有，我明确说明了吗？
- [ ] 我没有用外部知识"补充"答案吗？

通过所有检查后，再返回答案给用户。
