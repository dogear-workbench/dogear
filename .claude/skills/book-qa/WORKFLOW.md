## 工具调用顺序

### 标准流程

1. **LoadAnalysis** (可选)
   - 了解书籍类型和结构
   - 帮助理解如何组织答案

2. **SearchBookContent** (必需，优先使用 summary 模式)
   - 快速定位相关章节
   - 返回摘要和评分

3. **GetCitationContext** (如需要)
   - 获取原文片段
   - 提供上下文

4. **RequestMoreInfo** (如无结果)
   - 请求用户提供更多细节
   - 建议可能的搜索方向

## 决策树

### 何时使用哪个搜索模式？

```
问题类型判断
    │
    ├─ 全书概览问题（"这本书讲了什么"）
    │  └─→ 使用 LoadAnalysis，直接用分析结果回答
    │
    ├─ 具体内容问题
    │  │
    │  ├─ 关键词明确 → SearchBookContent(searchMode: "summary")
    │  │
    │  ├─ 摘要不足 → SearchBookContent(searchMode: "full")
    │  │
    │  └─ 仍无结果 → RequestMoreInfo
    │
    └─ 需要精确引用 → GetCitationContext
```

### 何时调用 RequestMoreInfo？

在以下情况下调用 RequestMoreInfo：
1. 两次搜索（summary + full）都无结果
2. 结果相关度都很低（评分 < 10）
3. 用户问题过于模糊（如"那个什么..."）

## 关键词提取策略

### 中文关键词提取
- 问题中的实体词：人名、地名、书名
- 动作词：发生、做、说、想
- 描述词：特点、原因、结果、影响

### 多关键词组合
使用 AND 逻辑：
- 主词 AND 次要词
- 同义词 OR 组合

### 示例

**问题：** "主角第一次见到反派是在哪里？"

**提取关键词：**
- 主词：主角、反派、见到、第一次
- 组合：(主角 OR 主人公) AND (反派 OR 敌人) AND (见到 OR 相遇)

## 结果评估标准

### 相关度评分解读

| 分数范围 | 含义 | 处理方式 |
|---------|------|----------|
| > 50    | 高度相关 | 直接使用 |
| 20-50   | 中等相关 | 检查内容，谨慎使用 |
| 10-20   | 低相关 | 多个结果综合判断 |
| < 10    | 不相关 | 忽略或二次搜索 |

### 信息充足性判断

**充足的条件：**
- 至少有一个高分结果 (> 30)
- 内容直接回答了问题
- 引用片段清晰完整

**不充足的标志：**
- 只有低分结果
- 内容过于片段化
- 需要推断或猜测

## 常见场景处理

### 场景 1: 用户问"书中有讲X吗？"

```
1. SearchBookContent(query="X", searchMode="summary")
2. 如果有结果 → 确认并说明在哪些章节提到
3. 如果无结果 → SearchBookContent(query="X", searchMode="full")
4. 如果仍无 → 说明书中没有提到X
```

### 场景 2: 用户问"详细解释Y"

```
1. SearchBookContent(query="Y", searchMode="summary")
2. 找到相关章节后，GetCitationContext 获取详细内容
3. 基于原文详细说明
```

### 场景 3: 用户问"谁/在哪里/什么时候"

```
1. 直接 SearchBookContent(query="具体名称/地点", searchMode="summary")
2. 如需精确信息，GetCitationContext
3. 给出明确答案 + 引用
```

## 边界情况处理

### 问题超出书籍范围
- 明确说明书中没有相关内容
- 不要用外部知识"补充"

### 多个章节都有相关内容
- 综合各章节内容
- 分别标注每个来源

### 搜索结果相关度低
- 尝试不同的关键词组合
- 说明找到了一些相关但不完全匹配的内容
- 询问用户是否是这个意思
