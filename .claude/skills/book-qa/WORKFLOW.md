# Book QA 工作流程

## 核心决策流程

```
用户问题
    │
    ▼
提取关键词（2-5个）
    │
    ▼
SearchBookContent(searchMode="summary")
    │
    ├─────────────────┬─────────────────┐
    ▼                 ▼                 ▼
高分结果(>30)    中低分(10-30)     无结果(<10)
    │                 │                 │
    ▼                 ▼                 ▼
直接回答      SearchBookContent  SearchBookContent
                ("full")          ("full")
                      │                 │
                      ▼                 ▼
                ┌─────┴─────┐     无结果
                ▼           ▼         │
            有结果      无结果        ▼
                │           │      RequestMoreInfo
                ▼           ▼         │
            回答+引用  RequestMoreInfo  │
                              └───┬───┘
                                  ▼
                              明确说明未找到
```

## 问题类型与处理方式

| 问题类型 | 首选操作 | 后续操作 |
|---------|---------|---------|
| "书中有讲X吗？" | Search(summary) | 有则说明章节，无则说明未找到 |
| "详细解释Y" | Search(summary) | GetCitationContext → 详细回答 |
| "谁/在哪里/何时" | Search(summary) | 直接答案+引用 |
| "全书讲了什么" | GetBookInfo | 概述 |

## 关键词提取策略

```
问题: "主角第一次见到反派是在哪里？"

提取关键词:
- 核心词: 主角、反派、见到
- 修饰词: 第一次、哪里

组合搜索: "主角 反派 见到 第一次" (空格分隔)
```

## 结果评估标准

| 评分范围 | 处理方式 |
|---------|---------|
| > 50 | 直接使用，高度可信 |
| 20-50 | 检查内容后使用 |
| 10-20 | 多个结果综合判断 |
| < 10 | 忽略或换关键词重搜 |

## 边界情况处理

### 搜索无结果
1. 换 searchMode="full" 重试
2. 尝试同义词组合
3. 仍无则明确说明未找到

### 多章节相关
综合所有来源，分别标注：
```markdown
关于X，书中提到:
1. [第一章] 简要说明...
2. [第五章] 详细阐述...
```

### 信息不足
明确告知用户需要更具体的搜索词或确认章节范围。
