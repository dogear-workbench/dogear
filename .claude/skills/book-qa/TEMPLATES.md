# Book QA 回答模板

## 标准问答（找到内容）

```markdown
根据原文，[直接回答] [章节标题]。

[可选补充] [其他章节]。
```

## 找不到内容

```markdown
很抱歉，搜索了所有章节后，没有找到与"[主题]"相关的内容。

**已搜索关键词：** [关键词列表]

这本书主要讲述的是[基于 GetBookInfo 的概述]。
```

## 多个来源

```markdown
关于[主题]，书中在不同章节都有涉及：

1. [第一章] - [说明]
2. [第五章] - [说明]
3. [第十章] - [说明]

综合来看，[总结]。
```

## 请求澄清

```markdown
为了更好地回答您的问题，能否请您提供更多细节？

比如：
- 您想了解哪个方面？
- 有没有具体的关键词或章节？
```

## 引用格式

| 类型 | 格式 |
|------|------|
| 单一章节 | `[第一章：章节标题]` |
| 带位置 | `[第一章：章节标题] (位置: 123-456)` |
| 多章节 | `[第一章] [第三章] [第五章]` |

## 回答风格

- **语气：** 专业、客观、基于事实
- **结构：** 直接答案 → 详细说明 → 引用来源
- **避免：** "可能"、"应该"、模糊表述
