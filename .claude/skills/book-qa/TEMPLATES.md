## 标准问答模板

适用于：找到明确答案，单一来源

```
根据原文，[直接回答用户问题]。

[引用章节]

[可选：提供简短的上下文或说明]
```

**示例：**
```
根据原文，主角张三出生于一个小镇 [第一章：起源]。

他的童年并不富裕，这影响了他后来的性格发展。
```

## 找不到内容模板

适用于：搜索后无相关结果

### 基础版

```
很抱歉，我在搜索了书籍的所有章节后，没有找到与"[搜索关键词]"相关的内容。

这本书主要讲述的是[使用 LoadAnalysis 获取的书籍概述]。
```

### 建议版

```
很抱歉，我在搜索了书籍的所有章节后，没有找到与"[主题]"相关的内容。

可能的原因：
- 书中确实没有涉及这个主题
- 描述这个内容的章节使用了我没有搜索到的关键词

您可以：
1. 提供更具体的章节名称或关键词
2. 确认这本书是否包含您要查找的内容
```

## 多个来源模板

适用于：答案来自多个章节

### 按时间线

```
关于[主题]，书中在不同章节都有提到：

1. [第X章：标题] - [简要说明该章节的内容]
2. [第Y章：标题] - [简要说明该章节的内容]
3. [第Z章：标题] - [简要说明该章节的内容]

综合来看，[总结性回答]。
```

**示例：**
```
关于主角的性格变化，书中在不同阶段都有描述：

1. [第一章：起源] - 主角性格内向，不善言辞
2. [第五章：改变] - 经历事件后，开始变得勇敢
3. [第十章：蜕变] - 最终成为自信的领导者

综合来看，主角经历了一个完整的成长弧线。
```

### 按主题分类

```
关于[主题]，可以从以下几个方面来理解：

**方面 1：[标题]**
- 内容来自：[章节引用]
- 详细说明：[基于原文的内容]

**方面 2：[标题]**
- 内容来自：[章节引用]
- 详细说明：[基于原文的内容]
```

## 请求更多信息模板

适用于：问题过于模糊，需要澄清

### 基础澄清

```
为了更好地回答您的问题，能否请您提供更多细节？

比如：
- 您想了解[主题]的哪个方面？
- 有没有具体的关键词或章节？
```

### 方向建议

```
我在搜索"[关键词]"时没有找到完全匹配的结果。

不过，我找到了一些相关内容：
- [相关章节 1] - [简要描述]
- [相关章节 2] - [简要描述]

请问您是想了解这些内容吗？还是其他方面？
```

## 全书概览模板

适用于：用户问"这本书讲了什么"

```
这本书是[类型：小说/非虚构/技术书/其他]，主要讲述[核心主题]。

**主要内容：**
- [方面 1] [引用章节]
- [方面 2] [引用章节]
- [方面 3] [引用章节]

**核心观点/主题：**
[使用 LoadAnalysis 获取的核心观点]，[引用相关章节]

**适合读者：**
[如果有说明，引用来源]
```

## 章节详解模板

适用于：用户问某个章节的具体内容

```
[章节标题]的主要内容如下：

**概述：**
[章节摘要]

**关键内容：**
1. [要点 1] - [原文引用或概括]
2. [要点 2] - [原文引用或概括]
3. [要点 3] - [原文引用或概括]

**与全书的关系：**
[该章节在全书中的作用，与前后的联系]
```

## 人物分析模板

适用于：用户询问人物信息

### 基础信息

```
[人物名称]是书中的[角色定位：主角/配角/反派等]。

**基本信息：**
- 首次出现：[章节引用]
- 身份/职业：[引用来源]
- 关系：[与其他人物的关系，引用来源]

**性格特点：**
- [特点 1]：[举例或引用，章节引用]
- [特点 2]：[举例或引用，章节引用]

**主要经历：**
[概括人物的主要经历和变化，引用相关章节]
```

### 人物关系

```
[人物 A] 和 [人物 B] 的关系如下：

- [关系描述 1] [章节引用]
- [关系描述 2] [章节引用]

他们的关系在故事中经历了[变化过程] [相关章节]。
```

## 引用格式规范

### 单一引用
```
[第一章：章节标题]
```

### 带位置信息
```
[第一章：章节标题] (位置: 123-456)
```

### 多章节引用
```
[第一章] [第三章] [第五章]
```

### 同一章节多处引用
```
[第一章：段落 A] [第一章：段落 B]
```

## 回答风格指南

### 语气
- 专业但友好
- 客观中立
- 基于事实

### 结构
- 先给出直接答案
- 再提供详细信息
- 最后标注来源

### 标点
- 使用中文标点
- 章节引用用方括号 []
- 列表用项目符号或数字

### 长度控制
- 直接答案：1-2 句话
- 详细说明：根据内容需要
- 避免冗长：聚焦用户问题
